# Мини-магазин (стартер-пак)

Основа проекта на Vite + TypeScript. Разметку, стили и логику магазина нужно написать самостоятельно. Само задание — в файле `Web_Programming_TypeScript_Assignment_RU.md`.

## Что нужно

- [Node.js](https://nodejs.org/) (актуальная LTS-версия)
- Редактор кода, например VS Code

Проверить установку:

```bash
node -v
npm -v
```

## Запуск

1. Откройте папку проекта в терминале (в VS Code: `Terminal → New Terminal`).
2. Установите зависимости:

   ```bash
   npm ci
   ```

3. Запустите режим разработки:

   ```bash
   npm run dev
   ```

4. Откройте в браузере адрес, который появится в терминале (обычно `http://localhost:5173`).

Чтобы остановить сервер, нажмите `Ctrl + C` в терминале.

## Команды

| Команда             | Что делает                                   |
| ------------------- | -------------------------------------------- |
| `npm run dev`       | Запускает сервер разработки                  |
| `npm run typecheck` | Проверяет типы TypeScript (без сборки)       |
| `npm run build`     | Проверяет типы и собирает проект в `dist/`   |
| `npm run preview`   | Запускает локальный просмотр собранной версии |

Vite при запуске только преобразует TypeScript и не проверяет типы, поэтому периодически запускайте `npm run typecheck`.

## Структура проекта

```
index.html        — разметка страницы
src/main.ts       — логика (TypeScript)
src/style.css     — стили
public/           — статические файлы
tsconfig.json     — настройки TypeScript (включён strict)
```

## Частые проблемы

- **`npm: command not found`** — Node.js не установлен или терминал нужно перезапустить.
- **Порт занят** — Vite сам выберет следующий порт, смотрите адрес в терминале.
- **Ошибки после распаковки архива** — убедитесь, что выполнили `npm ci` в папке, где лежит `package.json`.
